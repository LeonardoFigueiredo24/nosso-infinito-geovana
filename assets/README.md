# Arte do coração

`heart-petals.png` é o original transparente gerado com a ferramenta de imagens para este projeto. `npm run photos` gera a versão WebP utilizada na abertura.

Direção: coração escultórico formado por pétalas de rosa, tons rosé e vinho, luz suave, composição frontal, fundo transparente, sem texto. A animação, os reflexos de movimento, as ondas e as partículas são implementados no navegador.
